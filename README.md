## 📖 项目简介

developer-roadmap 是知名开发者学习网站 [roadmap.sh](https://roadmap.sh) 的官方内容仓库,收录了 80 余条社区驱动的交互式职业成长路线图。每条路线图把一个技术方向拆成可视化知识图谱,点击任意节点即可展开该主题的讲解与学习资源,解决"想入门却不知道按什么顺序学什么"的问题。内容覆盖前端、后端、全栈、DevOps、AI、数据、安全、设计等方向,并配套工程最佳实践和自测题库,是全球开发者最常用的职业规划与自学参考之一。

## ✨ 主要特性

- 🗺️ 80+ 条交互式路线图:前端、后端、全栈、DevOps、AI 工程师、数据、安全、设计等方向全覆盖
- 🖱️ 节点可点击:路线图上的每个知识点都能点开查看详细讲解与精选学习资源
- 🤖 紧跟技术趋势:收录 AI Engineer、AI Agents、Prompt Engineering、Claude Code、Vibe Coding 等新兴方向
- ✅ 工程最佳实践:后端/前端性能优化、代码评审、API 安全、AWS 等可交互实践清单
- ❓ 自测题库:JavaScript、Node.js、React、前端、后端问题集,帮你检验并提升知识水平
- 📂 内容即 Markdown:每个知识点都是独立的 md 文件,结构清晰,便于查阅、贡献与复用
- 🌍 社区驱动:全球开发者持续维护,合并的改动会自动同步到 roadmap.sh 网站
- 🆓 完全免费:线上版本 roadmap.sh 免费开放,无需注册即可学习

## 🚀 快速开始

1. **在线使用(推荐)**:打开 [roadmap.sh](https://roadmap.sh),挑一条感兴趣的路线图,沿着节点顺序逐个学习。
2. **不知从哪开始**:先看官方[入门指南](https://roadmap.sh/get-started),它会根据你的方向推荐合适的路径。
3. **本地查阅内容**:把仓库克隆下来,所有路线图正文都在 `roadmaps/` 目录下:

```bash
git clone git@github.com:nilbuild/developer-roadmap.git --depth 1
cd developer-roadmap
```

4. **内容组织方式**:每条路线图的内容位于 `roadmaps/<roadmap-slug>/content/<topic-slug>@<node-id>.md`,每个 md 文件对应一个知识点;文件名中的节点 ID 用于关联图上的节点,请保持文件名不变。
5. **参与贡献**:阅读 [contributing.md](https://github.com/nilbuild/developer-roadmap/blob/master/contributing.md),可以补充内容、新增路线图、提修改建议或在 Issue 中讨论想法。
6. **维护者工具**:`scripts/` 目录是维护者使用的内容同步工具,详见 [scripts/readme.md](https://github.com/nilbuild/developer-roadmap/blob/master/scripts/readme.md)。
