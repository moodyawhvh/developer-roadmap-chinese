## 仓库结构

本仓库保存了 [roadmap.sh](https://roadmap.sh) 网站上所有路线图背后的内容。

```
roadmaps/<roadmap-slug>/content/<topic-slug>@<node-id>.md
```

每个 Markdown 文件对应路线图上一个知识点的正文内容。文件名中的节点 ID(node id)负责把内容与图上的知识点关联起来,因此请保持文件名原样不动。合并进主干的改动会自动同步到网站。

```bash
git clone git@github.com:nilbuild/developer-roadmap.git --depth 1
cd developer-roadmap
```

`scripts/` 目录存放维护者使用的内容同步工具,详情见 [scripts/readme.md](./scripts/readme.md)。
