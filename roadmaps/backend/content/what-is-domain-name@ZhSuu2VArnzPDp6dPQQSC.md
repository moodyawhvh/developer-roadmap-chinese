# 域名

域名是人类可读的互联网地址，它会被解析为 IP 地址供计算机识别。域名由二级域名（"example"）和顶级域名（".com"）组成，由注册商管理，为用户提供友好的网站导航方式，取代难以记忆的数字 IP 地址。
