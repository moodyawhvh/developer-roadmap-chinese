# 域名

域名是对人类友好的网址（例如 [google.com](http://google.com)），用来代替数字形式的 IP 地址。它由二级域名（"google"）和顶级域名（".com"）组成。域名需要通过域名注册商注册，对于品牌建设和线上业务至关重要。DNS 负责将域名解析为 IP 地址，使其可被访问。
