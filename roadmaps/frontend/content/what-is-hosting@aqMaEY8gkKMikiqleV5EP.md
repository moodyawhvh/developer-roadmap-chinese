# 主机托管（Hosting）

Web 托管将网站文件存储在服务器上，使网站能够在线访问。托管类型包括共享托管（一台服务器承载多个网站）和独立托管（独占整台服务器）。服务商还提供电子邮件、域名和安全证书等附加服务。托管对网站的性能和可访问性至关重要。
