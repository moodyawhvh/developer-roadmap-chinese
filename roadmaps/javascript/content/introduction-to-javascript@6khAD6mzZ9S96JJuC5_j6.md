# JavaScript 简介

JavaScript 是一种高级解释型编程语言,最初的设计目的是为网页添加交互性。它运行在浏览器中,借助 Node.js 也可以运行在服务器端。JavaScript 是唯一能在网页浏览器中原生运行的语言,这使它成为前端 Web 开发的基石。
