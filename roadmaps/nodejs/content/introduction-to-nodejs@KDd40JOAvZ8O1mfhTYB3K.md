# Node.js 简介

Node.js 是一个让你能够在服务器端运行 JavaScript 的运行时环境。它构建在 Chrome 的 V8 JavaScript 引擎之上,采用事件驱动、非阻塞 I/O 模型,被广泛用于构建 Web 服务器、API 和命令行工具。

- [@official@Node.js](https://nodejs.org/en/)
- [@official@Node.js 文档](https://nodejs.org/en/docs/)
