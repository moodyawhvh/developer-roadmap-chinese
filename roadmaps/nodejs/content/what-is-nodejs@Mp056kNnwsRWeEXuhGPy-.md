# 什么是 Node.js?

Node.js 是一个跨平台的开源 JavaScript 运行时,能够在浏览器之外执行代码。它由 Ryan Dahl 于 2009 年创建,目的是让 JavaScript 可以用于服务器端脚本。与传统服务器环境不同,Node.js 以异步方式处理请求,因此非常适合 I/O 密集型应用。
