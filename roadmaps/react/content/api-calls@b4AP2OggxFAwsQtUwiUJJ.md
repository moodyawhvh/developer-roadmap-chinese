# API 调用

API(Application Programming Interface,应用程序编程接口)是软件与软件之间的接口,让不同的应用程序能够相互通信、交换信息或功能。企业可以借此访问另一家公司的数据、代码片段、软件或服务,从而扩展自己产品的功能——同时节省时间和成本。在 React.js 应用中发起 API 调用有多种可选方案。
